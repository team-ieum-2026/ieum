## 바뀌지 않은 것

- 문제 정의: 취업 여부를 묻는 전화 중심 사후관리에서 미취업 수료생일수록 멀어지는 문제
- 핵심 흐름: 맞춤 공고 선제 제공 → 지원 · 패스 · 도움 요청 → 근거 연결 서류 → 코디네이터 검토
- 검증 지표 3종: 매칭 Top-3 적합률 70%, 서류 근거 일치율 95%, 상태 분류 정확도 85%
- 시연 데이터: 팀원 본인의 교육 결과물 (주인공 민준)
