# AI 평가 설계 (1쪽)

지표 3종의 채점 대상 · 채점자 · 기준 · 집계 방법. 판정 세부 규칙은 `LABELING.md`, 루브릭 코드는 `rubric.py`.
**목표값은 결과를 보기 전(11/1)에 확정 커밋**하고, 결과 파일에 채점에 쓴 커밋 해시를 기록한다.

## 지표 3종

| | ① 매칭 추천 (AI-B) | ② 서류 생성 (AI-A) | ③ 상태 분류 (BE-B) |
| --- | --- | --- | --- |
| **채점 대상** | **test 수료생 12명**의 Top-3 카드 (최대 36장). 공고 풀 379건 = 실제 138 + 일반 150 + 정답 · 함정 91 | **test 수료생 12명 × 공고 1건 = 서류 12건**의 AI 문장 (기술 요약 · 프로젝트 bullet · 자기소개서, 약 100문장). 기업 정보 FOUND 4 · PARTIAL 4 · NOT_FOUND 4로 배정 | 시드 수료생 50명 |
| **채점자** | 정답표(`gold/pair_labels.csv`)로 자동. **정답표에 없는 카드만** 사람 2명 (FE-A · FE-B) | 사람 2명 (FE-A · FE-B). 문장 + 연결된 근거 인용 + 원문을 보고 판정 | 자동 |
| **기준** | 루브릭 2 적합 · 1 부분 · 0 부적합 (직무 · 경력 · 학력 · 지역 · 필수 기술 전부) | 2 일치 (근거가 그대로 뒷받침) · 1 과장 (수치 · 범위 · 역할을 부풀림) · 0 불일치 (근거 없음 · 내용 다름). 문체 · 맞춤법 정리는 과장이 아님 | 시드 `student_status` 와 같으면 정답 |
| **핵심 지표** | **Precision@3** = 2점 카드 / 전체 카드 | **근거 충실도** = 2점 문장 / AI 문장 · **허위율** = 0점 문장 / AI 문장 | **정확도** |
| **보조 · 통과 조건** | 명백 부적합률 (0점 카드 비율). 맞는 공고 없는 10번(test)은 2점이 아닌 카드가 1장이라도 나오면 실패 | 공고 반영도 (원본 vs 재작성 중 이 공고에 더 맞는 쪽, 사람 판정 승률). **기업 정보 조작 0건** (PARTIAL · NOT_FOUND 서류, 스크립트 1차 → 사람 확인) | — |
| **목표 (제안)** | Precision@3 ≥ 67% (3장 중 2장) · 부적합률 ≤ 10% | 충실도 ≥ 95% · 허위율 ≤ 1% · 반영도 ≥ 70% · 조작 0건 | 100% (규칙 기반이라 틀리면 버그) |
| **함께 보고** | 실제 공고만 / 전체, 흔한 / 드문 직무, Top-3 출처 분포, 무작위 기준선 대비 차이, dev 8명 점수(튜닝에 쓴 수료생임을 밝힘) | 제외율 (`excludedSentenceCount` / 전체 생성 문장), 자료 충실 / 부실별 | — |
| **응답 시간 p95** | 추천 ≤ 5초 | 서류 ≤ 60초 | — |

모든 비율은 **95% 신뢰구간(Wilson)과 함께** 보고하고, 사람 채점은 **2명 사이 일치도(Cohen's κ)**를 먼저 확인한다 (0.8 미만이면 기준 문구를 다듬고 다시 채점).

## 개발 중 지표 (dev 8명, 자동)
- 매칭: 정답률 · **함정 진입률(우선)** · 미판정 비율. 추천 카드별 점수와 어긋난 조건까지 공개
- 서류: 근거 검증 통과율 · 제외율 · 기업 정보 조작 자동 검사 · 공고 반영도(Gemini 판정)
- test 12명은 최종 전 1~2회만 실행하고 점수만 본다
